# 🐍 Classic Snake Game

A simple, minimalist **retro Nokia-style Snake Game** built with Python's built-in [`turtle`](https://docs.python.org/3/library/turtle.html) graphics module.

## ✨ Features

* 🐍 Classic Snake gameplay
* 🎮 Keyboard controls
* 📱 Retro Nokia-inspired design
* 🍎 Food and score system
* 💥 Game-over detection
* 🐢 Built using Python's built-in `turtle` module

## 🕹️ Controls

| Key       | Action     |
| --------- | ---------- |
| `w` / `↑` | Move Up    |
| `a` / `←` | Move Left  |
| `s` / `↓` | Move Down  |
| `d` / `→` | Move Right |
|    `e`    | Exit Game  |

## 🚀 How to Run

### 1. Install Python

Make sure Python is installed on your computer.

Python **3.x** is recommended.

You can check your installed version with:

```bash
python --version
```

> **Note:** You don't need to install `turtle` separately. It is included with standard Python installations.

### 2. Clone the Repository

```bash
git clone https://github.com/vedantparikh21/The-classic-Game-.git
cd .\The-classic-Game-\
```

### 3. Run the Game

```bash
python main.py
```

Enjoy the game! 🐍🎮
